# Project purpose and requirements

Oslo Hack helps people in Oslo meet collaborators, build a small project, and share their work. It began as a one-page exercise and now has a local project wiki.

## Confirmed baseline

The [original requests](../raw/2026-10-22-user-requirements.md) require HTML/CSS/JavaScript and `photo.jpg`, phone support, navigation, an introduction, Meet/Build/Share, a footer, and a collapsible session plan. Friendly placeholders were allowed. The user prefers a dark background and does not like blue. The current lime accent is observed in code.

No login, payments, or database were requested. The user subsequently asked for a chatbot using Nemotron through Vercel AI Gateway; this explicitly expands the static-only runtime with a server-side API, while retaining a library-free frontend.

## Current conversion

Preserve evidence under `raw/`, maintain linked knowledge under `wiki/`, and use [agent instructions](../AGENTS.md) to make future changes traceable. Each feature has its own specification in [the index](index.md).

The user wants to target individual Markdown files for additions and enhancements. A feature specification guides an implementation; it does not replace executable code. The public chatbot's approved content has a narrower boundary than the development wiki.

## Authority and unknowns

Recommendations in [the roadmap](roadmap.md) are proposals unless a specific implementation is requested. Dates, venues, signups, hosts, capacity, and participant data are unconfirmed. See [open questions](open-questions.md) and the [evidence summary](sources/project-baseline.md).
