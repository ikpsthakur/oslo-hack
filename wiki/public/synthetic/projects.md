# Synthetic project catalogue

All projects and roles below are fictional examples, not active teams, finished Oslo Hack work, or open positions. Status of every record: sample-only. Do not invent contributors or live results. Always label these examples. See [store rules](index.md).

## PROJECT-001 — Bike stop helper

- Problem: someone wants an easier way to compare two example bike stations.
- Afternoon outcome: a single screen comparing two stations from a tiny mocked dataset.
- Example skills: JavaScript, interface design, and user testing.
- Beginner task: sketch the comparison screen and test whether the labels are understandable.
- Next enhancement: connect an actual public bike API after verifying its terms and live data format.
- Boundary: this fictional project does not supply real bike availability, predictions, or reservations, and is not the separate existing Oslo Bike Check application.
