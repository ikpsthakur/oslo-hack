# Project baseline evidence

The [selected user extracts](../../raw/2026-10-22-user-requirements.md) establish purpose, original constraints, design preferences, and wiki conversion. They do not constitute a full chat transcript.

The [dated local observation](../../raw/2026-10-22-code-observation.md) documents behavior, file equality, placeholders, and hosting configuration at the start of conversion. Code remains editable; consult [current architecture](../architecture.md) before relying on an old observation.

The [external reference record](../../raw/2026-10-22-llm-wiki-reference.md) identifies Karpathy's original idea file. [ADR 001](../decisions/001-project-wiki.md) records this project's adaptation.

Additional [user steering](../../raw/2026-10-22-feature-wiki-and-chatbot.md) requests feature-specific Markdown targets and a chatbot through Vercel AI Gateway using Nemotron. This supersedes the static-only architecture for chat, without adding accounts, payments, or a database.

The [synthetic-store request](../../raw/2026-10-22-synthetic-store-request.md) authorizes a fictional customer knowledge collection and its integration with chat. Its records must not become claims about real events or customers. See [the implemented store](../features/synthetic-knowledge-store.md).

See [project requirements](../project.md) and [open questions](../open-questions.md).
