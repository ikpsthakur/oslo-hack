# Project showcase

## Scope and current behavior

Show completed work with screenshots, links, lessons, and permitted contributor credits.

## Code and dependencies

Expected root [HTML](../../index.html) and [CSS](../../style.css). Requires actual projects and publication permission. Related [project ideas](project-ideas.md).

## Acceptance criteria

Every listed project has a working link or honest non-public state. Credits and images are permitted. Examples are not disguised as completed Oslo Hack outcomes.

## Evidence and validation

Based on [project requirements](../project.md) and [baseline evidence](../sources/project-baseline.md). This feature is a recommendation; no implementation is claimed.
