# Footer

## Scope and current behavior

Footer contains the brand, a short tagline, a back-to-top link, and the current year set by JavaScript.

## Code and dependencies

Root [HTML](../../index.html): `footer`, `#year`. [JavaScript](../../script.js): year assignment. [CSS](../../style.css): footer layout.

## Acceptance criteria

Back-to-top reaches #top. Current year appears with JavaScript; fallback text remains usable without it. Footer fits phone width.

Based on [project requirements](../project.md) and [baseline evidence](../sources/project-baseline.md). The documented baseline was inspected locally on 2026-10-22. Re-test affected behavior after changes; no fresh browser pass is implied by this page.
