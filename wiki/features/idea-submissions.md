# Bring your idea

## Scope and current behavior

Let visitors propose a small project. Choose a real delivery channel before implementing submission behavior.

## Code and dependencies

Depends on [host/contact](host-contact.md), [project ideas](project-ideas.md), and a confirmed receiving mechanism.

## Acceptance criteria

A submission has a short description, desired help, and realistic scope. Tell the user where information goes and acknowledge only actual delivery. No database is introduced without expanding scope.

## Evidence and validation

Based on [project requirements](../project.md) and [baseline evidence](../sources/project-baseline.md). This feature is a recommendation; no implementation is claimed.
