# Join a session

## Scope and current behavior

Give visitors a real way to express interest or join. Start with a confirmed email or signup destination; do not invent one.

## Code and dependencies

Expected root [HTML](../../index.html): session CTA. Depends on [host/contact](host-contact.md) and [session details](session-details.md).

## Acceptance criteria

A clear Join button reaches the real destination. It explains what happens next. No pretend signup success. Confirm what personal information, if any, is collected before adding a form.

## Evidence and validation

Based on [project requirements](../project.md) and [baseline evidence](../sources/project-baseline.md). This feature is a recommendation; no implementation is claimed.
