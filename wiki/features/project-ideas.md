# Project ideas

## Scope and current behavior

Show a few achievable project ideas, required skills, and an afternoon-sized outcome. Examples may be labelled illustrative.

## Code and dependencies

Expected root [HTML](../../index.html): new project section; [CSS](../../style.css): cards. Related [Meet/Build/Share](meet-build-share.md).

## Acceptance criteria

Each idea has a title, short outcome, skills needed, and clear example/active status. Cards work on phone. Chat answers distinguish examples from active teams.
