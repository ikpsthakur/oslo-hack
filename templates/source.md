# Source capture template

Copy this template to a new dated Markdown file in `raw/`, fill it in, and ask an AI to ingest it. Remove instructions and empty sections before registering the source. Do not put credentials or participant personal information here.

- Title:
- Original author or speaker:
- Source URL or origin:
- Published/observed date, if known:
- Captured date:
- Capture type: exact excerpt / own notes / summary / reference record

## Material

Put the original notes or a clearly labelled excerpt here.

## Context

Explain why this source matters and what its limitations are. An idea in a source is not automatically a confirmed requirement.

After saving, ingestion registers the SHA-256 in `raw/manifest.json`, creates a summary under `wiki/sources/`, links relevant topics, updates the index, and appends the log. See [AGENTS.md](../AGENTS.md).
